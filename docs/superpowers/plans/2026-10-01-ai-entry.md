# AI giriş ve ayarlar uygulama planı

**Hedef:** OpenAI ile açık işlemi kaydetmek; anahtar ve parola ayarlarını panelden yönetmek.

**Mimari:** Ağ ve AI yorumlama ayrı server/ai modüllerinde; FinanceService yalnız doğrulama/muhasebe yapar. UI otomatik kayıt sonucunu yeniler ve belirsiz taslağı mevcut forma aktarır. İstek kimliği yeni SQLite migration ile atomik kalıcı kayıt sağlar.

**Teknoloji:** React/TypeScript, Express, Node 22 fetch, OpenAI Responses JSON Schema, SQLite/Drizzle, Vitest.

## İşler

- [x] Anahtar ayar servisi: private file, atomik 600 yazım, configured/model okuması, OpenAI model erişimi testi. Ayar route'ları exact-origin ve mevcut auth arkasında.
- [x] AuthService parola değişimi: eski parola ve token tekrar doğrulama, deneme sınırı, salt/hash yenileme, bütün oturum iptali. Geçici fixture testleri.
- [x] AI istemcisi ve işlem servisi: katı JSON Schema, bounded istek/yanıt/zaman/concurrency, refusal/incomplete hata; yalnız izinli alanlar/referanslar/para doğrulaması. Finans validator ile kesin kayıt, aksi confirmation.
- [x] Migration: ai_entry_receipts(request_id PK,input_hash,result_json,created_at). commit sonucu ve işlem aynı SQLite transaction içinde; önce/sonra receipt kontrolü; retry farklı metin reddi.
- [x] API/CLI: /api/parse yalnız AI taslağı; /api/ai/transaction AI kayıt; CLI parse/add metin AI, add --data yapılandırılmış manuel kalır. Testler sağlayıcı sınırını enjekte eder; gerçek üretim verisi yok.
- [x] UI: Ayarlar sayfası, anahtar/model/test, parola formu; quick entry AI ile ekle, belirsizde form, saved'de revision/toast; istek kimliği yalnız React belleğinde ve tekrar hata sonrası korunur.
- [x] Türkçe README/API/PWA/DEPLOYMENT güncelleme: internet ve OpenAI veri gönderimi, anahtar/yedek dosyaları, bağlantı etkinleştirme; yanlış offline/AI aboneliği yoktur iddialarını düzelt.
- [x] Tam test/build, bağımsız inceleme, secret taraması ve public push; mevcut sunucuda önce yedek sonra güncelleme.
- [x] Canlı HTTPS ayarlar/key-missing/fonksiyon akışı, telefon görünümü; geçici test DB'sinde gerçek yazım; üretim kayıt sayıları korunur.

## Doğrulama sonucu

Yerelde ve Linux yayın sunucusunda 14 dosyada 186 test geçti; TypeScript ve üretim derlemesi başarılı. Bağımsız incelemede bekleyen AI isteğinin oturum iptalinden sonra kaydetmesi ve build ortamında OpenAI anahtarı bulunabilmesi düzeltildi. Geçici defterde açık işlem kaydı/belirsiz taslak akışı tarayıcıda doğrulandı. HTTPS üretiminde ayarlar ve parola formu açılıyor; 375 piksel genişlikte yatay taşma yok. Finans kayıt sayıları değişmedi, SQLite bütünlük kontrolleri başarılı. Üretimde anahtar henüz tanımlı değil; gerçek OpenAI yorumlaması kullanıcı kendi anahtarını ekledikten sonra etkinleşir.
