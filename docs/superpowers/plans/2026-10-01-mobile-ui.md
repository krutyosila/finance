# Mobile UI Implementation Plan

**Goal:** Fit all finance screens on mobile and make entry/navigation accessible without horizontal scrolling.

**Architecture:** Keep the current hash navigation and native dialogs. Share safe-area and navigation dimensions through CSS variables, render narrow tables as labeled cards, and expose AI entry through a floating button.

**Tech Stack:** React 19, TypeScript, Vite, CSS, native dialog, Playwright browser verification.
